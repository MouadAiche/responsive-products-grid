## 🛠️ Features  
🧱 Responsive grid layout (4 → 3 → 2 columns)  
🎨 Modern gradient header design  
🪄 Smooth hover animation on product cards  
📱 Fully responsive using CSS Grid & media queries  
🧩 Clean and minimal UI

## 🧠 How It Works  
Product cards are structured using semantic HTML  
CSS Grid controls the responsive column layout  
Flexbox aligns and centers card content  
Media queries adjust layout for tablet and mobile screens  
Hover effects use `transform` and `box-shadow` transitions  
All styling and responsiveness handled with pure CSS — no JavaScript needed
